# First-answer assessment and focused review

Each learner can submit a selected question once per step. Identical transport retries reuse the receipt; changing the answer or request ID cannot overwrite the first attempt. Placement and normal practice exclude attempted questions. Explicit review sessions prefer unseen questions, then allow a previously answered question in a newly selected step. The first recorded answer remains the immutable assessment baseline. Placement remains adaptive and bounded; an unasked concept is reported as unassessed, never as directly demonstrated knowledge.

After placement, stop automatic practice and show an assessment derived from the first recorded answer for each question. Extend authenticated graph review with counts, wrong-question evidence and a review plan: errors first, prerequisites of errors next, unassessed concepts, then correctly answered concepts for maintenance. Mark graph foundations as important without inventing curriculum weights. Use current source-grounded graph descriptions and citations for review, not generated unverified teaching content.

No destructive migration or rewrite of historical attempts. Preserve wrong first answers even when historical duplicate attempts exist. Tests cover duplicate submission, immutable baseline, review ordering and unassessed labels. Live acceptance uses a separate learner so existing learner results remain intact.

Adaptive review reads current graph mastery, checks transitive prerequisites and
returns to weak foundations before revisiting the originating concept. Review
updates mastery and scheduling without changing first-answer assessment counts.
