# P5 web demo specification

Vietnamese learners can enter a goal or attach a syllabus, choose quick/deep research and Free/Pro, follow a research trail, explore an automatically laid-out knowledge map, and practice with cited Socratic hints and a DecisionTrace panel.

This first slice is explicitly a local mock demonstration, not live research. No learner credentials or secrets are used. Arbitrary entered topics must not be presented as genuinely researched; the sample subject is clearly identified. Only verified fixture questions are displayed. Answer keys are kept outside the public item shape. Sena celebrates understanding, never speed.

Acceptance: responsive desktop/mobile shell; keyboard-accessible navigation and forms; distinct research, map, learning and review screens; clickable graph nodes; MCQ feedback and prerequisite remediation; hint ladder with source links; prior/posterior and alternatives in the trace; uploads clearly marked local-only; reduced-motion support. No backend or shared contract edits.
