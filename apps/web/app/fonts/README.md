# Local fonts

Large page titles and Sena's guide heading use Dancing Script (400–700), a connected handwriting face. It is self-hosted from `dancing-script/` with its upstream OFL license. Small headings remain Be Vietnam Pro for legibility.

Source: https://github.com/google/fonts/tree/main/ofl/dancingscript

Small headings use Be Vietnam Pro, with real Semibold (600) and Bold (700) files. Both weights include Vietnamese characters. Files are in `be-vietnam-pro/`, with the upstream license beside them.

Source: https://github.com/google/fonts/tree/main/ofl/bevietnampro

Lora variable fonts (regular and italic) are retained for the journal's decorative typography. All fonts are self-hosted through `next/font/local`.

Source: https://github.com/google/fonts/tree/main/ofl/lora

The files retain the upstream SIL Open Font License in `OFL.txt`. No font request is made to Google when viewing the app. Both font files were checked for the Vietnamese precomposed character range U+1EA0–U+1EF9 and the additional Vietnamese base vowels and D-stroke.
